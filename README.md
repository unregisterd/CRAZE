# CRAZE
一款风格化的 3D 第三人称小镇探索游戏。你将扮演旅人 **Luci**，漫步在小镇中，与形形色色的居民交谈、接受委托、完成任务，在轻松悠闲的氛围里慢慢拼凑出小镇的故事。

## 游戏简介

- **类型**：3D 第三人称 / 休闲探索 / 任务冒险
- **引擎**：Unity 2022.3.62f3c1（URP）
- **风格**：卡通渲染、小镇街区探索、NPC 对话与任务

玩家可以在小镇街区中自由走动，通过与 NPC 对话接取任务、寻找物品、奔走于不同角色之间。目前包含多条支线，例如帮 **玛丽** 找回走失的三只小猫，或替 **SwimBoy** 从 **艾伦** 那里要回被拿走的泳圈。

## 角色与任务

**角色**
- **Luci**：玩家操作的主角
- **玛丽**：委托你寻找三只小猫的居民
- **SwimBoy**：泳圈被拿走的居民
- **艾伦**：拿走了 SwimBoy 泳圈的家伙

**任务示例**
- 《寻找丢失的小猫》：帮玛丽找回大白、小白、太白三只猫
- 《不知所云的泳圈》：从艾伦手里要回 SwimBoy 的泳圈，并归还给他

## 技术实现

- **对话系统**：JSON 数据驱动，支持线性推进、选项分支、条件判断（根据背包物品走不同对话），并可由选项触发任务、发放物品。
- **任务系统**：数据化任务定义，支持多目标、目标前置依赖，区分「收集 / 对话 / 交互」三类目标并实时刷新进度。
- **物品系统**：`ItemDatabase`（物品定义表）统一管理物品的名称、图标、描述等信息；背包 UI 采用格子布局，格子由对象池生成与复用。
- **存档系统**：基于 `ISaveable` 接口的通用存档框架，支持多存档槽位。
- **UI**：任务追踪 HUD、任务面板、对话面板、交互提示等。
- **第三人称控制**：基于 Invector Third Person Controller。
- **可拓展空间**：物品、背包、对象池等系统均已预留接口，便于后续玩法继续扩充。
